# Roadmap — gated by evidence

## Working foundation
Local-first web interface; editable paths and assumptions; transparent ranking and blockers; scenario stress tests; JSON portability; stdio MCP tools and skill prompts; 24 portable founder protocols; zero-dependency builds and CI.

## Thinking canvas (v0.6, implemented)
Fluid animated canvas, drag-to-connect, inline keyboard flow, on-canvas suggestions, a next-move coach, tool and skill recommendations, and a deterministic futures scan over every combination of choices. Polish/English UI follows the content.

## Shared brain (v0.7, implemented)
Canvases live as plain-text Markdown in the team's own Git repository next to how-we-work, brand and skills; folder sync in Chromium browsers, ZIP elsewhere; MCP tools and a CLI so agents work from the same files. Minimal default UI.

Not done (would need explicit consent and design): pushing to GitHub from the browser, OAuth, live multi-user editing, conflict resolution beyond "newer file wins".

## Next: prove user value
- Observe five real decision sessions, including abandoned flows. Do not substitute praise for usage.
- Add source provenance and quality grading. A text source note must not automatically confer high confidence.
- Add decision snapshots, undo/history and comparison between revisions.
- Extend Polish/English localization beyond the canvas to the analysis views.
- Test keyboard and screen-reader access on actual devices.

## Then: platform integrations
- Secure, authenticated remote MCP transport with user isolation and consent.
- ChatGPT app integration after remote MCP and platform registration.
- Explicitly reviewed import of AI-proposed paths and cited evidence.
- Optional browser extension / embedded widgets only after behavioral validation.

## After retention and willingness-to-pay evidence
- Shared team workspaces, audit logs and collaboration.
- Pricing for collaborative value, not operator-funded AI inference.
- Privacy and data protection review before storing customer accounts.

No users, revenue, virality, production deployments or official AI-platform approvals are claimed by this plan.
